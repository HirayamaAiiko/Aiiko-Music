Aiiko Music

A music player for your personal library.

Aiiko Music is a local music player for Windows, designed for personal music collections. It brings together playback, albums, artists, playlists, lyrics and metadata in one place.

Download for Windows Source code on GitHub

Windows 10 & 11 · Open source (GPL-3.0)

Features

Library

  • Local music library
  • Album and artist browsing
  • Playlist management
  • Search across the whole library

Playback

  • 10-band equalizer
  • Queue and shuffle
  • Gapless playback
  • Audio visualizer

Lyrics & metadata

  • Lyrics, including .lrc files and online search
  • Lyrics editor
  • Metadata editor
  • Album art

Interface

  • Floating mini player
  • Fullscreen view
  • Appearance and accent customization
  • Keyboard shortcuts

Integrations

  • Discord Rich Presence
  • Last.fm scrobbling
